# Olho Privacy Policy

Last updated: April 27, 2026

## Local-First Data Handling
1. Olho stores screenshots and recordings locally in the user's browser profile.
2. Olho does not upload screenshots or recordings.
3. Olho does not create an account.
4. Olho does not sell data.
5. Olho does not use analytics.
6. Olho does not track browsing history.

## Permission and Access Behavior
7. Olho only accesses the active tab when the user starts a capture action.
8. Olho only accesses screen, microphone, or camera when the user starts recording and grants browser permission.

## User Control and Deletion
9. Local data can be deleted from the gallery or settings.
10. Clearing browser data may remove local Olho data.
11. Exported files are controlled by the user.

## Additional Notes
- Olho does not use telemetry, remote logging, remote configuration, or hosted share links.
- Share helpers only prefill user-initiated drafts (for example Jira, GitHub, Trello, or mailto). File attachment is always manual and user-controlled.
- Data is stored locally through IndexedDB Blob storage and local extension settings storage.
